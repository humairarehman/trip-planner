# Smart Travel Planner with Chat Feature ✈️

A Flutter-based travel planning app that helps users explore destinations 
and connect with travel partners through real-time chat.

## Features
- Explore travel destinations
- Create personalized trip plans
- Real-time chat with travel partners
- Firebase Authentication
- User-friendly responsive UI

## Tech Stack
- Flutter & Dart
- Firebase (Authentication + Realtime Database)
- GeoDB API (Destinations)
- Foursquare API (Places)
- OpenWeatherMap API (Weather)
